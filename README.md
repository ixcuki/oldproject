# nearby

Мобильное веб-приложение живого пульса кампуса СГУ (Саратовский государственный университет). Показывает места на карте с live-статусами, ленту запросов Pulse, отзывы, XP/уровни, рейтинг студентов и AI-ассистента кампуса.

---

## Важно: LLM-токен не хранится в репозитории

Файл `.env` исключён из git через `.gitignore`. Ключ к языковой модели (Haiku через RouterAI) находится только на сервере разработчика и **никогда не попадает в репозиторий**.

Чтобы запустить проект локально, создай `.env` на основе `.env.example` и укажи свой ключ:

```bash
cp .env.example .env
# открой .env и вставь свой LLM_API_KEY
```

## Технологии

### Фронтенд
- **React 19** + **TypeScript** — UI-компоненты и типизация
- **Vite** — сборщик, dev-сервер
- **Tailwind CSS** — утилитарные стили
- **shadcn/ui** — компонентная библиотека (Sheet, Select, Input и др.)
- **Lucide React** — иконки
- **Leaflet** — интерактивная карта (тайлы OpenStreetMap FR)
- **React Router** — клиентская маршрутизация

### Бэкенд
- **Python 3.9+** + **FastAPI** — REST API
- **SQLite** (WAL-режим) — хранилище данных (`data/unipulse.db`)
- **Pydantic** — валидация входных данных
- **PBKDF2-SHA256** — хэширование паролей
- **RouterAI / Claude Haiku** — AI-ассистент кампуса (OpenAI-совместимый шлюз)

### Инфраструктура
- Polling каждые 20 секунд для live-обновлений
- JWT-подобные сессионные токены (хранятся в `localStorage`)
- Геолокация через браузерный API
- PWA-метатеги, мобильный viewport 390×844

## Быстрый старт

```bash
# 1. Зависимости бэкенда
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Настроить .env
cp .env.example .env
# вставить LLM_API_KEY в .env

# 3. Запустить сервер (сид-данные создаются автоматически)
UNIPULSE_SEED=1 python -m server.main

# 4. Зависимости и сборка фронтенда
cd web
npm install
npm run build
# или для разработки:
npm run dev
```

Сервер поднимается на `http://127.0.0.1:8000`. Фронтенд раздаётся им же из `web/dist/`.
